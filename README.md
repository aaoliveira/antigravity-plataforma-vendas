# Pacote de Engenharia --- Plataforma de Inteligência para E-commerce

Ordem de leitura e execução: 1. `PRD.md` 2. `BACKLOG_MVP.md` 3.
`PROMPT_000_GOVERNANCE.md` --- executar primeiro no Google Antigravity.
4. `PROMPTS_MVP.md` --- executar um prompt por vez, respeitando os
gates. 5. `PROMPTS_EVOLUCAO.md` --- executar somente após homologação do
MVP e revalidação de políticas.

O pacote define requisitos e prompts de referência. Antes de cada
integração, o Antigravity deve verificar a documentação oficial
atualizada, registrar evidências e bloquear qualquer capacidade não
comprovada. Não há garantia de risco zero de restrição por marketplaces;
a estratégia é minimizar riscos por conformidade e controles técnicos.
